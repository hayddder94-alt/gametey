# خطة تطوير متجر شركة المؤمل

خطة مرحلية مبنية على طبيعة الشركة: **كهربائيات وأثاث ومنزلية في النجف الأشرف، بيع نقدًا أو بالتقسيط، وعميل يعتمد على واتساب أولًا.**
كل مرحلة تُسلّم قيمة تجارية مباشرة قبل الانتقال للتالية.

---

## الوضع الحالي (الأساس المكتمل ✔)

- متجر مفتوح بدون حسابات: تصفح/بحث/فلاتر/عروض، خيارات ديناميكية، نقدي وتقسيط بمحرك أسعار خادمي آمن.
- سلة محفوظة، طلب برقم فريد يُحفظ في قاعدة البيانات ثم تحويل سلس لواتساب `9647821296460`.
- لوحة إدارة بثلاثة حسابات **بدور ADMIN موحّد كامل الصلاحيات** (مفروضة في الـ Backend) + سجل عمليات كامل + حماية رفع الصور + إحصائيات ورسوم بيانية حقيقية من قاعدة البيانات.
- بنية قابلة للتوسع (Express + SQLite بمعزل واضح للطبقات).

## قواعد تنفيذ الخطة

1. **واتساب أولًا:** أي ميزة جديدة يجب أن تقلل خطوة يدوية على واتساب أو تجيب عن سؤال متكرر عليه.
2. **لا حسابات للعملاء:** التتبع والولاء برقم الهاتف فقط — هوية المتجر «بدون تعقيد».
3. **التقسيط مقدس:** كل ميزة مالية تُدقق بسجل عمليات وتُختبر بمعادلة: (سعر + خيارات + رسوم − خصم) × كمية.
4. **قياس قبل توسع:** لا تُبنى ميزة مرحلة لاحقة قبل تحقق مقياس نجاح المرحلة الحالية.
5. **أمان مستمر:** أي مسار جديد يمر عبر RBAC وسجل العمليات، والأسعار تُحسب في الخادم دائمًا.

## توصيات فورية (قبل أي مرحلة)

- ربط نطاق فعلي (مثل `almuammal.iq`) مع HTTPS وتفعيل `secure` لكوكي الإدارة وضبط `JWT_SECRET` قوي عبر متغيرات البيئة.
- جدولة نسخ احتياطي يومي لقاعدة البيانات ورفع الصور.
- مراقبة بسيطة: سجل أخطاء يومي + تنبيه إذا توقف الخادم.
